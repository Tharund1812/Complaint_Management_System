# Complaint Management System

## 📌 Project Overview

The Complaint Management System is a MySQL-based database project designed to manage, track, and analyze customer complaints efficiently.

The system manages customers, complaints, employees, departments, complaint categories, priorities, complaint statuses, assignments, and resolution details.

- GitHub
